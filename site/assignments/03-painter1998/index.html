本地运行

PowerShell 命令如下。Python 版本为 3.11；默认教学使用仓库内的公开样本，不需要 Earthdata 登录。

git clone https://github.com/peijianliu/modern-remote-sensing-homework.git
cd modern-remote-sensing-homework/assignments/03-painter1998-snow-sma
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -c requirements-lock.txt -e ".[notebook,dev]"
& .\.venv\Scripts\python.exe scripts/build_notebooks.py --prepare-assets
& .\.venv\Scripts\python.exe scripts/build_notebooks.py
& .\.venv\Scripts\python.exe scripts/build_notebooks.py --prepare-workspace
& .\.venv\Scripts\python.exe -m jupyterlab build/workspace

Linux / macOS 将解释器换为 .venv/bin/python。首次准备 MathJax 需要联网并核对固定哈希，此后构建离线使用缓存；HTML 离线包已包含资源。站点输出到仓库根 build/site/，练习副本在作业目录 build/workspace/，已有练习不覆盖。单本 .ipynb 需要完整仓库中的共享模块和数据。

数据 方法与复现级别

正演输出称反照率，影像观测称反射率。原始系数用于重建，去阴影雪比例用于相对覆盖；MGS诊断保留越界值，FCLS施加物理范围约束。报告中的历史库谱结果与本轮公开库谱重算分别标注。

L1：三份 Notebook 与教学数据重算。L2：完整公开 AVIRIS 输入到当前模型的重建，以及两景 MODIS 与公开参考的重新聚合和评价。L3：全部历史输入、实验条件和报告复原。阅读各级运行说明 · 数据来源 · 贡献说明。
