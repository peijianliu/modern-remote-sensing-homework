本地运行

在 Python 3.11 环境克隆仓库，进入本次作业目录。以下命令使用 PowerShell：

python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -e ".[notebook,dev]"
& .\.venv\Scripts\python.exe scripts/build_notebooks.py

macOS / Linux 使用 .venv/bin/python。也可启动 JupyterLab，按 01、02、03 的顺序阅读和执行。

如何理解结果

  • 01 读取已有 SNICAR / WW80 计算缓存；60°为课程模拟设定。
  • 02 从缓存雪谱重新合成并解混，真值来自明确的混合比例。
  • 03 从公开影像派生教学数据重算统计与代表像元；历史库谱结果与新增影像背景结果分别标注。
  • MODIS 雪标志用于产品一致性，WorldView 公开派生覆盖参考用于独立覆盖对照。
