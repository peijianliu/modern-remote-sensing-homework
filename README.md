## Painter 1998 雪粒径与光谱混合分析

研究雪粒径变化如何影响反射率、光谱混合解混和像元雪覆盖估计。案例以经典论文的流程为主线，结合五份小组作业的实验设计，在统一的 2013 年 AVIRIS / MODIS 数据上补充对照。
