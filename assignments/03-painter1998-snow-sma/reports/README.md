# Painter 1998 综合实验报告

[阅读综合报告 PDF](painter1998-integrated-report.pdf)

报告整合雪光谱正演、已知比例混合实验、AVIRIS 实景解混、尺度退化、MODIS 产品一致性及外部覆盖验证。五人作业的方法贡献、原文图表对应关系和数据来源列于报告附录。

新增固定粒径扫描在共同可归一化的 60,949 个像元上统计；三种雪谱模型的比例比较采用共同的 62,861 个像元。历史库谱基准与新增影像背景实验分别标注。1 km 雪标志对照仅有 17 个唯一合格单元，参照均为无雪，召回率保留为空值。

三份 [Notebook](../notebooks/) 提供物理规律、Fig. 3 重新解混以及实景统计和制图的运行过程。教学数据见 [data/demo](../data/demo/README.md)，公开使用与再分发范围见 [数据政策](../PUBLIC_DATA_POLICY.md)。
