# Painter 1998 综合实验报告

[阅读综合报告 PDF](painter1998-integrated-report.pdf)

报告整合 WW80 雪光谱正演、已知比例混合与七种失配实验、AVIRIS 实景解混、尺度退化、MODIS 产品一致性及独立覆盖验证。五人作业的方法贡献、原文图表对应关系和数据来源列于报告附录。当前版本为 2026-10-27 教学验证修订版，41 个物理页面（含封面和独立目录）。

固定粒径扫描采用 60,949 个共同像元；三模型物理可行性比较采用 62,861 个共同像元。2013 年 406 个原生 1 km 候选最终保留 17 个阴性单元，用于说明面积支持与 QA 的影响。补充的 2016 年同日 MODIS 独立覆盖比较保留 1,416 个 500 m 单元，其中 463 个参考雪比例≥0.1；独立 1 km 状态比较为 408 个单元，含 123 个参照阳性。历史库谱、2013 影像背景、公开端元 Landsat 和新增 MODIS 分支分别解释。

三份 [Notebook](../notebooks/) 提供物理规律、Fig. 3 重新解混以及实景统计和制图的运行过程。教学数据见 [data/demo](../data/demo/README.md)，公开使用与再分发范围见 [数据政策](../PUBLIC_DATA_POLICY.md)。
